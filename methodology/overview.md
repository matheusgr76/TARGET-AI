# TARGET(AI) — methodology overview

TARGET(AI) applies the TARGET method to AI-assisted, agentic, and autonomous systems operating under uncertainty.

At its core, TARGET uses a recurring cycle:

```text
Target → Assess → Reason → Generate → Execute → Track → Assess
```

The cycle is not a one-way workflow. Feedback can change the next action, challenge the reasoning behind it, or question whether the target itself should remain unchanged.

In these experiments, particular attention is given to evidence: an AI output or completed action is not automatically treated as proof that the intended result was achieved.

This repository records practical experiments using those principles. It does not contain the complete TARGET(AI) methodology.

For the full framework, including its treatment of feedback, reasoning, evidence, state, autonomy, and implementation, see:

**[TARGET(AI): A Method for Goal-Directed Action, Tested Against AI and Autonomy](https://www.amazon.com/dp/B0HH8J89J8)**
by Matheus G. Reis.
